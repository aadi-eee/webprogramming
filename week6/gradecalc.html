Understanding If / Else

This program checks a student's score using conditional statements and assigns the appropriate grade.

JAVASCRIPT SOURCE CODE

script.js
// Grade Evaluator
let score = 85;
if (score >= 90) {
console.log('A');
}
else if (score >= 80) {
console.log('B');
}
else if (score >= 70) {
console.log('C');
}
else {
console.log('F');
}
The program checks each condition in order and stops at the first true condition.
