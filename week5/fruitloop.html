01. The Step Loop

COUNTING LOOP
●   JAVASCRIPT CODE step-loop.js
// Repeat the loop N times
for (let i = 1; i <= 5; i++) {
console.log('Step ' + i);
}
for loop: initialization → condition → update. The loop stops when the condition becomes false.

02. The Fruit Loop

ARRAY ITERATION
●   JAVASCRIPT CODE fruit-loop.js
// Loop through an array
let fruits = ['apple', 'banana', 'cherry'];
 
for (let fruit of fruits) {
console.log(fruit);
}
for...of loop: takes each fruit from the array and runs the code once for that fruit.

01. The Array

Stores multiple values in one variable. Each item has an index starting at 0.

02. The Loop

The for...of loop visits each item in order, one at a time.

03. The Output

console.log() prints the current item. Each iteration produces one output.
