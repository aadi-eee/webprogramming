JAVASCRIPT BASICS

Make the Counter Work

Click the buttons to update a variable and see the page change in real time.

●   HTML + JAVASCRIPTcounter.html
<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Counter</title>
</head>
<body>
<h2>Counter: <span id="count">0</span></h2>
<button onclick="change(1)">+ Add</button>
<button onclick="change(-1)">− Subtract</button>
<button onclick="reset()">Reset</button>
 
<script>
let count = 0;
function change(amount) {
count = count + amount;
document.getElementById('count').textContent = count;
}
function reset() {
count = 0;
document.getElementById('count').textContent = 0;
}
</script>
</body>
</html>
How it works: a variable stores the count, functions change its value, and getElementById() updates the displayed number.
