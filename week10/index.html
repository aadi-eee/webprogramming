How the week went

Monday: I learned how Git saves my work locally, then sent it to GitHub (repo: git-exercise).

My first commit

I made a folder, ran git init and committed one HTML file (a410168).

git init
echo "<h1>Hello Git</h1>" > index.html
git add index.html
git commit -m "Initial commit: add index.html"
git log --oneline
Working on a branch

I added a stylesheet on feature-style, and it only appeared on main after I merged (543270e).

git checkout -b feature-style
echo "body { font-family: sans-serif; }" > style.css
git add style.css
git commit -m "Add basic stylesheet"
git checkout main
git merge feature-style
git log --oneline --graph --all
Sending it to GitHub

I connected my local repo to a blank GitHub repo and pushed.

git remote add origin https://github.com/aadi-eee/git-exercise.git
git push -u origin main
Pull request

I changed the README on its own branch and merged it through pull request #1.

git checkout -b add-readme
git add README.md
git commit -m "Add README describing the exercise"
git push -u origin add-readme
git checkout main
git pull origin main

 

Friday: I used GitHub Pages to turn repos into real websites (repo: webpro-w9).

Going live

After pushing, I opened Settings, then Pages, picked main and the root folder, and my page appeared at this address.

git add index.html
git commit -m "Add index.html with my name and date"
git push -u origin main
The default 404 and my own

GitHub's own error page looks nothing like my site and gives no way back, so a visitor would be stuck. I wrote my own 404.html with a link home. Try a wrong address.

git add 404.html
git commit -m "Add custom 404 page"
git push

What I learned

The hardest part was getting started in the terminal. My first commit failed because the file had never been created, and my branch was called master instead of main, so I had to rename it.

What surprised me was how easily a live site breaks over small things. My portfolio pointed to a photo and a resume PDF that I had not pushed yet, so both were missing online until I added and committed them.

Next time I will run git status before every push and check the live site right away, and I will make smaller commits with clearer messages.
