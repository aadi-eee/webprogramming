Monday practice: Git

Three exercises and a pull request, all in one repository: git-exercise.

Exercise 1

Create your first repository

Goal: start a Git repository, create a file and make the first commit.

mkdir my-first-git
cd my-first-git
git init
echo "<h1>Hello Git</h1>" > index.html
git status
git add index.html
git commit -m "Initial commit: add index.html"
git log --oneline

Result: index.html showed up as untracked, then became commit a410168.

Exercise 2

Create a branch and merge it

Goal: make a feature branch, add a change and merge it back into main.

git checkout -b feature-style
echo "body { font-family: sans-serif; }" > style.css
git add style.css
git commit -m "Add basic stylesheet"
git checkout main
ls
git merge feature-style
ls
git log --oneline --graph --all

Result: back on main, ls showed only index.html. After the merge (a fast-forward to 543270e) style.css appeared too.

Exercise 3

Push your repo to GitHub

Goal: create an empty repository on GitHub and push my local commits to it.

git remote add origin https://github.com/aadi-eee/git-exercise.git
git remote -v
git push -u origin main

Result: both commits are on GitHub. Open the repository ↗

Extra

A pull request on GitHub

Goal: practise the collaboration workflow: branch, push, open a pull request and merge it.

git checkout -b add-readme
echo "# git-exercise" > README.md
git add README.md
git commit -m "Add README describing the exercise"
git push -u origin add-readme
# opened and merged the pull request on GitHub
git checkout main
git pull origin main
git log --oneline --graph --all

Result: pull request #1 was opened and merged, which created a merge commit on main. See pull request #1 ↗

Exercise 3

Create a custom 404 page

Goal: add my own 404.html so GitHub Pages serves it for missing pages.

git add 404.html
git commit -m "Add custom 404 page"
git push
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Not Found</title>
</head>
<body style="text-align:center;padding:60px;font-family:sans-serif">
  <h1>404 &mdash; Oops!</h1>
  <p>That page doesn't exist.</p>
  <a href="./">&larr; Back to Home</a>
</body>
</html>

Result: a missing URL now shows my own page. Try a missing page ↗
